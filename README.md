# EV-Charging-Demand-Prediction
Machine Learning-Based EV Charging Demand Prediction using XGBoost Classification and Regression with an Interactive Stream lit Dashboard.

# ⚡ EV Charging Demand Prediction

## Machine Learning-Based EV Charging Demand Prediction Dashboard

This project focuses on predicting Electric Vehicle (EV) charging demand using **Machine Learning**, with an interactive dashboard developed using **Streamlit**.

The project uses **XGBoost Classification and Regression** to analyze charging-related features and provide demand predictions.

## 📊 Dashboard Features

* ⚡ EV Charging Demand Prediction
* 🤖 XGBoost Classification
* 📈 XGBoost Regression
* 🔋 Charging Duration Analysis
* 🕒 Time-Based Demand Analysis
* 📅 Day, Month and Weekend Features
* 📍 Location-Based Inputs
* 📊 Interactive Streamlit Dashboard
* 📌 Demand Prediction Results

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* XGBoost
* Streamlit
* Plotly
* Jupyter Notebook

## 🤖 Machine Learning Models

**1. XGBoost Classifier**

Predicts the EV charging demand category, such as Normal Demand or High Demand.

**2. XGBoost Regressor**

Predicts a numerical EV charging demand value.

## 📁 Project Files

* `app.py` – Streamlit dashboard application
* `EV_Charging_Dashboard.ipynb` – Dashboard development notebook
* `EV_Charging_Demand_Analysis.ipynb` – Data analysis notebook
* `ev_charging_xgb_classifier.pkl` – Trained classification model
* `ev_charging_xgb_regressor.pkl` – Trained regression model
* `ev_charging_feature_columns.pkl` – Classification model feature columns
* `ev_charging_regression_feature_columns.pkl` – Regression model feature columns
* `requirements.txt` – Required Python libraries

## 🚀 How to Run the Project

**Step 1: Clone the repository**

```bash
git clone https://github.com/farishabanu7-cloud/EV-Charging-Demand-Prediction.git
```

**Step 2: Navigate to the project folder**

```bash
cd EV-Charging-Demand-Prediction
```

**Step 3: Install dependencies**

```bash
pip install -r requirements.txt
```

**Step 4: Run the Streamlit dashboard**

```bash
streamlit run app.py
```
